# Personal Portfolio

A beginner-friendly, responsive personal portfolio built with only **HTML**, **CSS**, and **JavaScript**.

## Files

- `index.html` — The main page structure and content.
- `styles.css` — All styling, layout, and responsive design.
- `script.js` — Interactive features like the mobile menu and contact form.

## How to Use

1. Open `index.html` directly in your web browser, or
2. Serve the folder with a simple local server:
   ```bash
   cd portfolio
   python3 -m http.server 8000
   ```
   Then visit `http://localhost:8000`.

## Features

- Fully responsive navigation with mobile hamburger menu.
- Smooth scrolling between sections.
- Clean, modern design using CSS custom properties.
- Working contact form (client-side demo).
- Scroll-reveal animations.
- Resume download button.
